# Klik Menu QR - Pedidos en Mesa

> Menú digital interactivo para comensales con fotos HD, personalización y auto-pedido.

## 🚀 Inicio Rápido
```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo en puerto 3011
npm run dev
```

## 🔗 Integración con Klik POS Matrix
Este módulo se conecta a la matriz central **Klik POS** a través del protocolo unificado de eventos WebSocket/REST.
